2. WATERMeDIA
-------------
This mod contains no WATERMeDIA code; it depends on the WATERMeDIA jar at
runtime only.  Note that WATERMeDIA itself is distributed under the PolyForm
Strict License 1.0.0, which is not an open source license; this mod neither
bundles nor redistributes it.
    https://github.com/WaterMediaTeam/watermedia

The optional Mixin in this mod (org.watermedia.androidbridge.mixin.RenderAPIMixin)
redirects a single native allocation call inside WATERMeDIA's RenderAPI, so that
a failing LWJGL aligned allocation falls back to WATERMeDIA's own direct-buffer
path instead of aborting the game during mod loading.  It is declared
"required": false, contains no WATERMeDIA code, and can be removed on its own.

3. Not bundled, but optionally supported
----------------------------------------
If an Android JNA dispatch library (libjnidispatch.so) is placed into the payload
directory, the bridge can point JNA at it when a launcher does not provide one
itself.  Builds published by this project do not ship that file - the launchers
that need it (for example FCL or PojavLauncher) already provide a matching build,
and the bundled copy would be a third party binary that never activates.
Anyone re-adding it must also ship its licence, which for the PojavLauncher build
is the GNU Lesser General Public License version 3.
    https://github.com/PojavLauncherTeam/PojavLauncher
